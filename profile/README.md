# Memstead

**Typed project knowledge for AI agents.** Memstead is the engine, CLI and MCP server that keep what an agent learns about a project as typed markdown in git, with a schema enforced on every write.

- **Engine, CLI & MCP server:** [memstead/memstead](https://github.com/memstead/memstead)
- **Website:** [memstead.com](https://memstead.com)
- **Homebrew tap:** [homebrew-memstead](https://github.com/memstead/homebrew-memstead)

> **Status: pre-1.0, in active development** — APIs, schemas, and formats may still change. Built in the open by [@dasboe](https://github.com/dasboe).
